# Granica — приложение для просмотра камер на границе

Проект состоит из двух частей:

- **backend/** — Node.js/TypeScript сервер, который агрегирует публичные камеры
  пограничных переходов и отдаёт их Android-приложению через REST API
  (плюс проксирует снимки камер, чтобы обойти CORS/hotlink-защиту и кешировать их).
- **android/** — нативное Android-приложение (Kotlin + Jetpack Compose),
  которое показывает список стран → пограничных переходов → камер,
  позволяет добавлять переходы в избранное и обновляет снимки в реальном времени.

## Реальные камеры "из коробки" (WSDOT, США)

В проект уже встроен **живой, официальный источник данных** — WSDOT
(департамент транспорта штата Вашингтон, США) публикует открытый API с
временем ожидания и камерами на переходах США↔Канада (Peace Arch, Pacific
Highway/Blaine, Lynden, Sumas на трассах I-5, SR-543, SR-539, SR-9):
- https://wsdot.wa.gov/traffic/api/Documentation/group___border_crossings.html
- https://wsdot.wa.gov/traffic/api/Documentation/group___highway_cameras.html

Чтобы включить эти данные:
1. Открыть https://wsdot.wa.gov/traffic/api/, ввести email в форму внизу
   страницы — бесплатный `AccessCode` придёт на почту (обычно мгновенно).
2. В папке `backend/` скопировать `.env.example` в `.env` и вставить код:
   ```
   WSDOT_ACCESS_CODE=ваш_код
   ```
3. Перезапустить `npm run dev` — в `/api/countries` появится страна
   `US-CA` с реальными переходами, временем ожидания (`waitMinutes`) и
   актуальными снимками камер (backend сам находит камеры WSDOT в радиусе
   3 км от каждого перехода).

Без ключа backend отдаёт только демо-запись — это ожидаемо, не ошибка.

## Приблизительная оценка очереди с ИИ

Backend может по свежему снимку камеры посчитать видимые автомобили и вернуть
приблизительное время ожидания. Это не официальное время и показывается в
приложении именно как оценка. Для включения добавьте в Vercel переменную:

```text
GEMINI_API_KEY=ваш_ключ
```

Дополнительно можно указать модель через `GEMINI_VISION_MODEL`; по умолчанию
используется `gemini-3.6-flash`. Endpoint запускается приложением вручную:

```text
GET /api/crossings/:id/ai-estimate?cameraId=:cameraId
```

Результат содержит `vehicleCount`, `estimatedWaitMinutes`, `confidence` и
`analyzedAt`. Если ключ, прямой снимок или ответ модели недоступны, backend
возвращает ошибку, а приложение не показывает выдуманное время.

## Реальные камеры Сербии, Боснии и Черногории (Хорватия, HAK)

Также подключены **реальные, проверенные вживую** камеры на границах Хорватии
с Сербией, Боснией и Черногорией — их публикует официальный Hrvatski autoklub
(HAK, Хорватский автоклуб) на `m.hak.hr`, без ключа и без ограничений. Каждая
ссылка вида `https://m.hak.hr/cam.asp?id=N` проверена напрямую (сервер отдаёт
`Content-Type: image/jpeg`). Список: `backend/src/config/crossings.json`,
страны `RS`, `BA`, `ME`. Время ожидания HAK не публикует — только снимки камер.

## Важно: откуда берутся остальные камеры

Легально можно использовать только **публичные** камеры, которые сами
пограничные/таможенные службы или операторы дорог публикуют в открытом доступе
(обычно это JPEG-снимки, обновляемые раз в 1–5 минут, реже — MJPEG/HLS-потоки).
Список переходов и ссылок на камеры хранится в
[`backend/src/config/crossings.json`](backend/src/config/crossings.json) —
это единственное место, которое нужно редактировать, чтобы добавить новую
страну/переход. Скрапинг сайтов, требующих авторизации, обход платных API или
встраивание камер без разрешения владельца делать не нужно — конфиг рассчитан
на официальные открытые источники.

В репозитории уже есть несколько реальных примеров (Литва/Латвия/Эстония —
погранслужбы этих стран публикуют веб-камеры переходов с Россией/Беларусью).
Остальные страны добавляются тем же способом — просто новая запись в JSON.

## Быстрый старт

### Backend

```bash
cd backend
npm install
npm run dev   # http://localhost:3000
```

API:
- `GET /api/countries` — список стран, у которых есть переходы
- `GET /api/crossings?country=LT` — переходы страны
- `GET /api/crossings/:id` — детали перехода (камеры, координаты, статус)
- `GET /api/crossings/:id/cameras/:cameraId/snapshot` — проксированный/кешированный снимок камеры (JPEG)
- `GET /api/crossings/:id/ai-estimate?cameraId=:cameraId` — приблизительная оценка очереди по снимку камеры

### Android

Открыть папку `android/` в Android Studio (Giraffe+), дождаться синхронизации
Gradle и запустить конфигурацию `app` на эмуляторе/устройстве (minSdk 26).
По умолчанию приложение обращается к `http://10.0.2.2:3000/` (адрес хоста
из эмулятора) — для реального устройства поменяйте `BASE_URL` в
`app/build.gradle.kts` (buildConfigField) на адрес вашего сервера.

## Структура

```
backend/
  src/
    config/crossings.json   # реестр стран/переходов/камер
    routes/                 # Express-роуты
    services/                # кеш снимков, работа с конфигом
    server.ts
android/
  app/src/main/java/com/granica/app/
    data/                   # Retrofit API, Room (избранное), модели
    ui/                      # Compose-экраны (страны, переходы, камера, избранное)
    di/                      # простая ручная DI (без Hilt, чтобы было проще собрать)
```

## Дальнейшие шаги (roadmap)

- Очередь/время ожидания: если у страны есть открытый API с временем ожидания
  (как у некоторых погранпереходов ЕС), добавить поле `waitTimeUrl` в конфиг
  и парсер в `backend/src/services`.
- Push-уведомления (Firebase Cloud Messaging) о посвободневшем переходе.
- Офлайн-режим: кешировать последние снимки в Room/DataStore.
